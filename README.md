# Synerise PHP SDK

---

## About
[Synerise](https://www.synerise.com) SDK for PHP. Allows access to Synerise APIs and overall integration.

## Requirements
* A Synerise workspace API Key
* PHP 8.0+

## Installing Synerise SDK with Composer

SDK is available over packagist. Some dependencies are optional and can be replaced with custom implementations

1. You can install it with the following command:

```shell
composer require synerise/php-sdk
```

2. Install suggested dependencies
```shell
composer require mobiledetect/mobiledetectlib
```

## Initialization

The repository provides autogenerated api clients that can be utilized on their own.
There's also a single entry point `ClientBuilder` which helps to initialize and authorize all the apis.

### Using ClientBuilder

`ClientBuilder` requires a `Synerise\Sdk\Api\Config` implementation and a `RequestAdapter`.

The SDK provides `RequestAdapterFactory` and `DefaultAuthenticationProviderFactory` to set these up:

```php
use Synerise\Sdk\Api\Authentication\DefaultAuthenticationProviderFactory;
use Synerise\Sdk\Api\ClientBuilder;
use Synerise\Sdk\Api\Config;
use Synerise\Sdk\Guzzle\ClientFactory;
use Synerise\Sdk\Guzzle\RequestAdapterFactory;

/** @var Config $config implementation of Config interface */

// Create the request adapter with authentication
$requestAdapterFactory = new RequestAdapterFactory(new ClientFactory());
$authProviderFactory = new DefaultAuthenticationProviderFactory($requestAdapterFactory);
$requestAdapter = $requestAdapterFactory->create(
    $config,
    $authProviderFactory->get($config),
);

// Build the client
$clientBuilder = new ClientBuilder($config, $requestAdapter);
```

### Accessing APIs

```php
// V4 API
$v4 = $clientBuilder->v4();

// Catalogs API
$catalogs = $clientBuilder->catalogs();

// Recommendations API
$recommendations = $clientBuilder->recommendations();
```

## Token Caching

The SDK supports token caching to reduce authentication requests. By default, tokens are cached in memory. For persistent caching, provide a PSR-6 or PSR-16 cache implementation:

### With PSR-6 Cache Pool
```php
use Symfony\Component\Cache\Adapter\RedisAdapter;
use Synerise\Sdk\Api\Cache\PsrItemPoolTokenCache;

// composer require symfony/cache
$cache = new RedisAdapter(RedisAdapter::createConnection('redis://localhost'));
$tokenCache = new PsrItemPoolTokenCache($cache);

$authProviderFactory = new DefaultAuthenticationProviderFactory(
    $requestAdapterFactory,
    null,
    $tokenCache,
);
```

### With PSR-16 Simple Cache
```php
use Symfony\Component\Cache\Psr16Cache;
use Synerise\Sdk\Api\Cache\PsrTokenCache;

$cache = new Psr16Cache(new RedisAdapter(RedisAdapter::createConnection('redis://localhost')));
$tokenCache = new PsrTokenCache($cache);
```
